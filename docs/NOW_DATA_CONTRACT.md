`make now-debug`는 같은 수집기를 `--no-history --no-save`로 실행한다.
`make premarket`, `make takesnapshot`의 수집기는 별개다.

## 2026-09-15 수정

- KIS 업무 응답 성공 및 필수 숫자 파싱을 확인한다. 결측은 JSON `null`, 화면 `N/A`로 보존한다. 실제 응답에 있는 0은 유효한 값이다.

- 실제 KIS 수급 응답에 없는 `etc_frgn_ntby_tr_pbmn`은 기타외국인 0으로 만들지 않는다. 주체 소계와 전체 수급 합계의 검증 범위를 구분한다.
- 실제 코스닥150 선물 응답의 `output3`은 `bstp_cls_code=2001`, KOSPI200이었다. `3003` 여부를 확인하고, 다르면 주식 지수 API로 코스닥150을 따로 조회한다. 별도 조회된 선물·현물 간 시각 정합성은 여전히 미검증이다.
- Yahoo 구간 수익률의 현재값과 관측 시각은 같은 마지막 유효 분봉에서 가져온다. 미래 분봉과 비정상 가격을 제외한다. 분봉이 없을 때만 quote의 가격과 시각을 함께 사용한다.
- 1h/2h 기준점은 해당 목표시각 이전 5분 이내에 있어야 한다. 짧은 시계열의 첫 값을 대체 기준으로 사용하지 않는다. 기준점 시각을 JSON에 보존한다. 지연 시세의 구간은 화면에 표시된 관측 시각에서 끝난다.
- 수급·프로그램 구간 변화는 현재와 과거의 유효한 관측 날짜·시각이 필요하다. 수집 시각 차이를 관측 구간으로 사용하지 않는다. 수급 1h/2h도 실제 구간을 검증한다. 현재 사용하는 KIS 응답은 관측 날짜가 없으므로 해당 델타는 제공하지 않는다.
- 첫 적립은 시초가가 아니다. 화면은 `당일 첫 수집 대비`로 표시한다. 이력은 시각순 정렬하고, 당일·과거·schema 2 레코드만 사용한다. 손상된 JSONL은 오류로 알리고 비교에 사용하지 않는다.
- 선물과 현물의 산술 차이는 `raw_spread / ALIGNMENT_UNVERIFIED`이다. 콘탱고·백워데이션 판정을 하지 않는다. 시간 정합성과 동일 계약이 확인되지 않은 스프레드 변화는 계산하지 않는다.
- 상승·하락·상한·하한은 응답 분류별 수치를 표시한다. 상·하한의 포함관계가 검증되지 않아 응답 분류합을 실제 전체 종목수로 단정하거나 상승비율·내부폭 판정에 사용하지 않는다.
- 조건 관측, 공식 발동 기록, 공식 해제 기록을 분리한다. 조건 관측 이력이나 경과 시간만으로 발동·해제를 만들지 않는다. CB3에는 시간 경과에 따른 자동 해제를 적용하지 않는다.
- `AssessPulse`와 화면의 요약은 같은 판정을 사용한다. 입력 부족을 중립·정상·우호로 바꾸지 않는다. 미검증 예측 신뢰도는 JSON `null`이며 종합은 `COMPOSITE_NOT_CIRCULABLE`이다. 개별 관측값은 계속 표시한다.
- JSON schema 2와 새 이력은 유효성, 출처, 시각, 안전장치, assessment를 보존한다. schema 1 이력은 원본을 유지하되 비교 기준에서 제외한다. JSON 사용자는 schema 변경 및 nullable 값을 반영해야 한다.

## 공식 이벤트 수동 입력

기존 날짜 없는 `OFFICIAL_EVENT_*` 환경변수는 사용하지 않는다.
`OFFICIAL_EVENTS_FILE` 또는 날짜별 `official_events_YYYYMMDD.json`에 다음 필드를 제공한다.

```json
[
  {
    "business_date": "YYYYMMDD",
    "source": "https://공식-기록-주소",
    "market": "KOSPI",
    "device": "SIDECAR_SELL",
    "triggered_at": "HH:MM:SS",
    "released_at": "HH:MM:SS"
  }
]
```

`released_at`은 확인된 경우에만 입력한다. 날짜·시간과 미래 이벤트 여부를 검증한다. 출처 URL의 내용을 자동 조회·검증하는 공식 이벤트 연동은 아직 없다. `TRIGGERED`는 입력된 발동 기록을 뜻하며, 해제 기록이 없으면 현재까지 계속 정지 중이라고 해석하면 안 된다.

## 기여도 재검증 후 변경 (2026-09-15)

기존 `KOSPIMarketCapSummary`는 우선주를 포함한 시장 시가총액 집계였다. 이를 KOSPI 기여도의 구성종목과 분모로 사용한 것은 잘못이다. 삼성전자우 한 행 또는 그 포인트만 빼서는 다른 종목의 가중치와 상위 10종목 선정이 복원되지 않는다.

장중 펄스는 별도의 `KOSPIIndexMarketCapSummary`를 사용한다.

1. 날짜별 `.mst` 원본 전체에서 `kospi_issu_yn`(field 58)이 `Y`이고 `prst_cls_code`(field 54)가 `0`인 집합을 만든다. 종목명 끝의 `우`나 종목코드만으로 분류하지 않는다.
2. 이 집합 전체의 `prdy_avls_scal`(field 65, 전일기준 시가총액·억원)을 더해 참고 비중의 분모로 삼고, 그 뒤 시가총액 순 상위 10종목을 선택한다.
3. 편입 표시가 있는 종목의 시가총액 결측·비정상, 불명확한 보통주 구분, 중복 코드, 분모와 구성종목 합계 불일치, 날짜 불일치를 거부한다. 상위 종목 시세 일부가 누락되면 부분합을 발행하지 않는다.
4. JSON sidecar schema 2에 편입 여부·우선주 구분·증권 그룹을 추가한다. 날짜별 파일명과 기존 재무 기준년월은 유지한다. 기존 sidecar도 원본 `.mst`에서 메타데이터를 갱신한다.
5. KIS의 편입 표시를 KRX 공식 구성종목 파일과 독립 대조하지 않았고, 공식 지수 산출주식수·기업행사 조정·기준일·동일시각 가격도 검증되지 않았다. 따라서 참고 시총비중은 `PROXY_NOT_OFFICIAL_INDEX_WEIGHTS`, `point_impact`는 `null`, 지수 영향·기여율은 `NOT_EVALUATED`다. 참고 비중을 최종 지수 기여도로 환산하지 않는다.

KIS 원본 필드 정의: [공식 샘플의 종목마스터정보(코스피).h](/Users/sunjinlee/workspace/fifi/external/open-trading-api/stocks_info/종목마스터정보(코스피).h).

2026-09-15 보존 원본 감사: 기존 집합 940종목·55,057,552억원 → 위 KIS 조건 집합 829종목·53,316,508억원. 제외된 우선주는 111종목이다. 이는 **KIS 원본 전수 대조 결과**이며 공식 KOSPI 구성종목 수나 최종 산출 분모의 확정값을 뜻하지 않는다. 증권 그룹 ST만 추가로 남기는 임의 필터는 사용하지 않는다. KIS 편입 표시가 있는 RT·IF도 대조 집합에 남기고 공식 집합 검증을 별도로 요구한다.
