# 장전 보고서 데이터 계약

적용 명령은 `make premarket` (`report premarket`)이다. `make now`의 pulse 및 `make takesnapshot`의 snapshot 수집·평가 경로는 별도이며 이 변경에 포함하지 않는다.

## 기준일과 출처

- 보고 대상일은 KST 기준이다. 자료 선택 상한(`cutoff_at`)은 실행 시각과 대상일 09:00 KST 중 이른 시각이다. 오후 재실행에서도 당일 장중·종가를 장전 현물 종가로 채택하지 않는다.
- 국내 지수·VKOSPI는 일별 응답에서 대상일 이전 행을 선택한다. KIS market-time에서 직전 거래일을 확보하면 그 날짜와 일치하는 행만 사용한다. 실패하면 날짜가 있는 Yahoo 국내 지수 일별 자료 또는 Naver VKOSPI 일별 자료를 사용한다.
- 국내 수급은 확인된 직전 거래일로 요청하고 응답의 실제 날짜를 재검증한다. 과거 거래일의 정상적인 0은 유효하며 당일 장전 초기값과 구분한다.
- 미국 현물은 Yahoo 일별 시계열에서 뉴욕시간 16:00이 선택 상한 이전인 완료 세션만 선택한다. 날짜는 미국 거래일로 표시하며 이전 일별 관측 대비 등락을 계산한다. 조기 폐장 당일 16:00 이전에는 보수적으로 직전 완료 세션을 유지한다.
- 유가·DXY·NQ·KRW=X는 시각이 확인되는 제공사 관측값이다. 상한 이후 관측 또는 미확보일 때에는 시작 시각으로부터 24시간이 지난 제공사 일별 바를 문맥 자료로 사용한다. 이 경로는 거래소 거래일이나 정산가를 인증하지 않으며, 원본 바 시각과 비교 바 시각을 보존한다. 최근 일별 바/관측이 7일을 넘으면 사용하지 않는다.
- KIS mktfunds는 억원, KOFIA 금액은 어댑터의 백만원을 100으로 나눈 억원이다. 통계의 실제 기준일을 보존하고 `LAGGED_CONTEXT_ONLY`로 표시한다.

## 미확보와 판정

- JSON `schema_version=2`. 숫자와 평가 결과의 미확보는 `null`이며 관측된 0을 지우지 않는다. `inputs`에 출처·단위·기준일·시각·세션·상태·미확보 사유를 포함한다.
- 표와 평가 입력은 같은 관측 객체에서 생성한다. 정상 KIS 응답은 `RESTResponse.FirstRow`/`Rows`로 읽고 사업 오류·빈 필드·비유한 숫자를 배제한다.
- 반도체 합성 가중치는 SKHY 35%, SOX 25%, MU 15%, NVDA 15%, ASML 10%다. 모든 구성원의 거래일 및 비교일이 일치해야 계산한다. 결측 가중치를 다른 종목에 재분배하지 않는다.
- ADR 환산비율·대응 국내 가격, 실제 NDF, 동일 계약 선물 비교가 검증되지 않아 프리미엄·NDF 갭·divergence는 미평가다. 코스피 지수를 ADR의 국내 주가로 사용하지 않는다.
- 레버리지 회전비, 예탁금 5일 추세, 담보 기반 마진콜 근접도, 일정 점수화·T+2 에코, CDS 기반 분류에는 검증된 구현/자료가 없다. 고정 예시 수치와 7월 일정은 제거했으며 명시적으로 미확보 처리한다.
- 현재 D/A/S의 필수 입력이 충족되지 않으므로 점수는 `null`, 종합은 `COMPOSITE_NOT_CIRCULABLE`이다. 후속 데이터 연결 없이 낮은 위험 등급을 재개하지 않는다.
- `coverage_pct`는 등록된 관측 항목의 값 확보율이다. 후행 문맥 자료를 포함하며 정확도·예측 신뢰도와 다르다. `confidence_pct`는 미평가(`null`)다. 시장 급변 경고 개수는 결측 집계에 사용하지 않는다.

## 저장·호환성

- 검증된 이력은 `PREMARKET_STORE_DIR/store.v2.json`에 원자적으로 저장한다. 기존 `store.json`은 그대로 보존하고 새 통계에 자동 편입하지 않는다.
- 같은 보고 대상일은 최신 조회 결과 전체로 갱신한다. 0이나 결측으로의 정정도 반영한다. 손상된 파일은 오류를 보고하고 덮어쓰지 않는다.
- 백분위는 실제 원자료 기준일을 중복 제거하고, 현재 기준일과 이후 관측을 제외한 60개/250개 이력이 확보돼야 계산한다. 부족하면 확보한 표본 수와 N/A를 출력한다.
- `--no-save`는 장전 보고서 이력을 저장하지 않는다. API 어댑터 자체의 인증·원자료 캐시는 별도로 동작한다.
- Go 및 JSON 소비자는 숫자 포인터/null과 버전 변경에 대응해야 한다. 기존 키는 가능한 한 유지하되 미검증 숫자·불리언은 null로 내보낸다.

## 검증

`go test ./internal/collector/premarket ./cmd/agent` 및 `go test -race ./internal/collector/premarket ./cmd/agent`.

회귀 사례는 실제 RESTResponse 인터페이스, 쉼표 숫자·0·결측, 전부 미확보인 등급, 9/14 장전 고정 입력, 부분 반도체 데이터, DST·미완료 미국 세션, 오후 재실행, 통계 기준일·단위, 이력 중복·표본 부족·구버전 격리를 포함한다.

## 1차 장전 자료 확장 (2026-09-14)

`make premarket`의 기존 실행 방법을 유지한다. JSON에는 `domestic_inputs`와 `calendar`가 추가되며 `store.v2.json`의 일별 레코드에도 함께 저장한다. 같은 대상일은 최신 실행 결과로 교체되므로 최초 아침 실행본을 영구 보존하는 기능은 아니다. `--json` 출력을 별도 파일로 보관하면 해당 실행본을 보존할 수 있다.

### 국내 수급·거래대금·주요 종목

- 코스피·코스닥의 외국인/기관/개인 전일 및 3·5거래일 누적 순매수를 추가한다. 누적에는 전일을 포함한다. KIS 일별 지수 행의 거래일과 수급 행을 대조해 필요한 날짜가 모두 존재할 때만 계산하며, 빠진 날짜를 더 오래된 날짜로 대체하지 않는다.
- `InquireInvestorDailyByMarket`의 기존 코스피 동작을 보존하고, `InquireInvestorDailyForMarket`을 추가해 코스닥(`KSQ`, `1001`)을 조회한다. 기존 표와 확장 표는 코스피 수급·지수 응답을 공유한다.
- 시장 거래대금은 전일 값과 **전일을 제외한 이전 20거래일** 평균 및 배수를 표시한다. 21개 날짜가 필요하며, 중복 날짜는 한 번만 사용하고 값이 충돌하는 중복 행은 거부한다.
- 삼성전자(005930), SK하이닉스(000660)는 KIS KRX(`J`) 일별 종가·등락률·거래대금·외국인/기관 순매수를 표시한다. 일별 응답의 실제 날짜가 국내 직전 거래일과 일치해야 한다. 현재가 요약 `output1`은 사용하지 않는다.
- KIS 시장 거래대금/시장·종목 투자자 순매수 금액은 백만원 → 억원(`/100`), 종목 일별 거래대금은 원 → 억원(`/100000000`)이다. 양수·음수·관측된 0을 모두 보존한다.
- 확장 자료는 `domestic_inputs`에 저장한다. 기존 D/A/S 점수 입력의 확보율을 새 문맥 자료로 부풀리지 않으며, 점수 산식은 변경하지 않는다.

### 상승·하락·보합 종목 수

- 출처: 금융위원회 주식시세정보 `getStockPriceInfo`, 환경변수 `DATA_API_KEY`.
- `basDt`로 날짜를 지정해 전체 페이지를 받고 `totalCount`, 페이지 순서, 모든 행의 날짜, ISIN 중복, 시장 분류, 종가·등락 숫자를 검증한다. 일부 페이지 실패 시 부분 집계를 공개하지 않는다.
- 제공사 시장 구분(KOSPI/KOSDAQ)의 **주식 전체**를 집계한다. 우선주 및 거래정지 종목을 포함할 수 있어 KOSPI 지수 구성종목 수나 다른 제공사의 상승·하락 종목 수와 범위가 다르다. `vs > 0` 상승, `< 0` 하락, `= 0` 보합이며 상승 비율의 분모는 셋의 합이다.
- 공공데이터는 장전 즉시 제공을 보장하지 않는 후행 공개 자료다. 전일 자료가 아직 게시되지 않았으면 `확인 불가`와 오류 사유를 표시한다. **오후 검증에서 전일 데이터가 조회됐다는 사실은 그날 아침에도 조회 가능했다는 뜻이 아니다.** 사후 재실행에서 과거 공개 시점까지 복원하지 않는다.
- 날짜 없는 KIS 현재 요약의 상승/하락 수를 전일 수로 간주하거나, 다른 날짜의 수급 필드 날짜를 종목 수에 붙이지 않는다.

### 공식 일정

- 자동 연결: [FOMC 공식 회의 일정](https://www.federalreserve.gov/monetarypolicy/fomccalendars.htm), [BLS 공식 ICS](https://www.bls.gov/schedule/news_release/bls.ics), [BEA 공식 ICS](https://www.bea.gov/news/schedule/ics/online-calendar-subscription.ics).
- 범위: 대상일 KST 00:00부터 7일 후 KST 00:00 미만. 발표시각이 명시된 경우 뉴욕 DST를 반영해 KST로 변환한다. FOMC 회의 날짜만으로 발표시각을 만들어내지 않고 현지 시작·종료일을 별도로 표시한다. 다음 해 회의는 잠정 일정으로 표시한다.
- 예정시각 경과는 실제 발표 확인과 다르다. 실제 발표값·시장 예상치·서프라이즈는 수집하지 않는다.
- 출처별 성공/오류를 독립적으로 보존한다. HTML 오류 응답, 빈 ICS, 미지원 시간대/반복 일정은 해당 출처의 미확보로 처리한다. 일부 출처가 실패해도 나머지 일정은 표시한다.
- 현재 한국은행·국내 경제지표, 기업 실적, 파생 만기·지수 정기변경은 미연결이다. 일정 범위가 제한되어 전체 상태는 `PARTIAL` 또는 `UNAVAILABLE`이며, 일정이 없다는 이유로 낮은 위험 점수를 부여하지 않는다.
- 일정 목록과 수집 상태는 출력 및 JSON에서 확인할 수 있다. 조회 시점은 보고서 실행 시점이며, 오후 재실행에서 아침 당시 공지 내용까지 복원하지 않는다.
