# `make takesnapshot` 데이터 계약

`premarket`, `now`, `takesnapshot`은 별도 수집기다. Snapshot은 요청 영업일의 일봉·일별 수급, 조회 당시 참고 시세, 후행 신용 통계를 각각 구분한다.

## 기준일과 관측 시각

- `business_date`/JSON `date`는 요청 영업일이다. `timestamp`와 `completed_at`은 실제 수집 시작·완료 시각이다.
- 장중은 `INTRADAY_PROVISIONAL`, 장후도 `POST_CLOSE_UNRECONCILED`다. 수집 완료가 거래소 확정을 뜻하지 않는다.
- 가격·수급은 날짜가 정확히 일치하는 행만 사용한다. 다른 날짜나 날짜 없는 현재값으로 대체하지 않는다.
- 과거 날짜 조회에는 현재 전용 해외 시세·선물·프로그램매매 및 현재 마스터 비중을 끼워 넣지 않는다.
- 관측 날짜/시간이 없는 현재 시세는 `TIMESTAMP_MISSING`. 선물 15:45, 현물 15:30, 닛케이 마감 시각을 상수로 채우지 않는다. ISIN과 최근월 분류를 만기일/달력 계약월로 바꾸지 않는다.

## 수급과 프로그램매매

- 일별 수급의 백만원→억원은 `/100`. 기타법인은 별도 행으로 보존한다. 외국인 합계에 이미 들어간 세부 외국인 행을 다시 더하지 않는다.
- 이전 거래일 수급은 같은 API 응답에서 이전 날짜의 수급을 읽는다. 과거 저장본은 당시 관측치로 보존하며 재조회 후속치와 혼동하지 않는다.
- 차익 필드는 공식 KIS 샘플의 `arbt_ntby_amt`, 비차익은 `nabt_ntby_amt`, 전체는 `all_ntby_amt`다. 기관 합계 코드 `8888` 및 공백이 있는 `기 관` 표기를 처리한다.
- 기관 합계와 금융투자·연기금 등 하위 행을 함께 합산하지 않는다. 시장 전체 프로그램 수치는 별도 전체시장 응답의 `arbt_smtn_ntby_tr_pbmn`, `nabt_smtn_ntby_tr_pbmn`, `whol_smtn_ntby_tr_pbmn`에서 읽고 합계 반올림 오차는 원자료 2백만원 이내만 허용한다.
- 산술 일치는 공식 확정이나 출처 시간 일치를 뜻하지 않는다. `canonical_total_eok`는 검증 전 `null`이다.
- 15:00/15:20/15:30 구간 변화에는 날짜와 정확한 시각이 있는 서로 다른 표본이 필요하다. 첫 행, 15:42, 가까운 수집 시각, 날짜 없는 HHMMSS로 대체하지 않는다.

## 지수 구성종목과 분모

- 집중도와 삼성전자+SK하이닉스 비중은 KIS 마스터의 `kospi_issu_yn=Y`, `prst_cls_code=0` 전체 모집단을 검증한 후 산출한다.
- 모든 구성종목 시총 합계와 분모 일치, 날짜, 중복, 우선주 분류, 결측 시총을 확인한다. 부분집합을 먼저 잘라 분모로 사용하지 않는다.
- 마스터의 시총은 전일 시총 필드다. 결과는 `PROXY_NOT_OFFICIAL_INDEX_WEIGHTS`; 공식 KRX 가중치·포인트 기여도가 아니다. 시장 전체 수급과 분모 범위가 검증되지 않은 비율은 `N/A`다.

## VKOSPI와 신용 통계

- VKOSPI 일별 조회 날짜는 보고 기준일이다. KIS 응답은 해당 날짜에서 과거 방향으로 내려온다. 14일 전을 조회해 과거 5일 평균을 최신 평균으로 쓰지 않는다.
- 5일 평균은 날짜가 있는 서로 다른 5거래일을 정렬해서 계산한다. 장중에는 오늘의 미완결 일봉을 평균에서 제외한다. 출처 관측 시각을 수집 시각으로 채우지 않는다.
- KOFIA FreeSIS 요청 `tmpV40=1000000`으로 백만원 단위를 명시한다. 빈 `unit`은 이 요청 계약 안에서만 백만원으로 해석한다. 명시 단위가 있으면 검증 후 변환하고, 알 수 없는 단위/필드 결측은 오류다.
- 기존 `tmpV40=100` 요청값을 천원으로 간주한 변환 때문에 결과가 10배 커졌다. 캐시 schema 2와 `amount_unit=KRW_MILLION`으로 구분하며 기존 캐시는 보존 후 새로 조회한다. 단위 불명인 캐시를 일괄 나눠서 재사용하지 않는다.
- KOFIA `*_mln / 100 = 억원`. KIS 자금 기준일과 KOFIA 기준일을 각각 표시한다. 지연 일수는 실제 날짜 차이로 계산한다. 예탁금 전일 증감은 같은 응답의 이전 기준일 잔고로 검산한다.
- KOFIA 보고 비율은 출처 보고값이며, 반대매매/전일 미수금 분모 재검산 전에는 검증 완료로 표시하지 않는다.

## 평가·저장

- 완결 거래일 수익률 정렬 및 전체 모델 입력이 검증되기 전에는 상관계수·위험회피·스트레스 점수를 `null / NOT_EVALUATED`로 유지한다.
- 수급 몇 개와 달력만으로 투매·숏스퀴즈·종가관리·리밸런싱·만기 차익거래를 판정하지 않는다.
- JSON schema 2는 Impact/Cumulative, 원자료 기준일·출처 시각·단위·상태와 결측 `null`을 보존한다. 이전 schema 저장본과 자동 수치 비교를 하지 않는다.
- 날짜별 최신 JSON/Markdown을 갱신하기 전에 이전 파일을 보존한다. 과거 보고서는 소급 덮어쓰지 않는다.

## 검증

Snapshot 및 KOFIA 회귀 테스트는 [공통 테스트 가이드](TESTING.md)에 따라 Ginkgo v2 + Gomega의 BDD 스타일로 작성한다. 날짜·단위·출처 범위 등 조건을 `Context`로 나누고, 기대 동작을 `It`으로 검증한다. 반복 오류 사례는 `DescribeTable`로 표현하며, 변환 시 기존 검증 범위를 유지한다.

`internal/collector/snapshot/testdata/kis_20260915.json`은 인증 정보를 제외한 실제 KIS 응답의 관련 행이다. 고정 입력 회귀 검증은 날짜·부호·단위·우선주·전체 분모·잘못된 구간 앵커·결측·JSON 보존을 확인한다. KOFIA 테스트는 명시적 백만원 요청 응답과 같은 날짜 KIS 예탁금을 대조한다.

공식 필드 참고: `external/open-trading-api/examples_llm/domestic_stock/investor_program_trade_today/`, `external/open-trading-api/stocks_info/종목마스터정보(코스피).h`. FreeSIS 원본은 https://freesis.kofia.or.kr/stat/FreeSIS.do?parentDivId=MSIS10000000000000&serviceId=STATSCU0100000060 이며 내부 화면 API는 변경될 수 있다.
